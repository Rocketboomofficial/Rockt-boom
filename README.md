# راکت بوم | Rocket Boom 🚀

بازی سه‌بعدی نبرد هوایی؛ آماده‌سازی‌شده برای انتشار روی GitHub Pages و ساخت اپلیکیشن با PWABuilder.

## امکانات PWA
- `manifest.webmanifest` با نام، رنگ‌ها، حالت مستقل و جهت افقی
- آیکون‌های PNG در اندازه‌های 192 و 512 پیکسل و آیکون maskable؛ همه‌ی فایل‌ها مستقیم در ریشه‌ی مخزن قرار دارند و پوشه‌ی assets وجود ندارد
- `service-worker.js` برای cache کردن پوسته‌ی برنامه و منابع CDN پس از بارگذاری آنلاین
- متاتگ‌های سازگار با مرورگرهای موبایل و Apple Touch Icon

## انتشار در GitHub Pages
1. تمام فایل‌های این بسته را مستقیم در ریشه‌ی مخزن GitHub بارگذاری کن؛ نیازی به پوشه‌ی assets نیست.
2. در **Settings → Pages**، انتشار از شاخه‌ی `main` و پوشه‌ی `/(root)` را فعال کن.
3. پس از انتشار، آدرس HTTPS سایت را باز کن و مطمئن شو بازی اجرا می‌شود.

## ساخت اپلیکیشن با PWABuilder
1. ابتدا سایت را با HTTPS منتشر کن؛ PWABuilder به آدرس عمومی سایت نیاز دارد.
2. به https://www.pwabuilder.com برو.
3. آدرس کامل GitHub Pages را وارد کن و **Start** را بزن.
4. بررسی‌های Manifest و Service Worker را مرور کن و هر هشدار باقی‌مانده را برطرف کن.
5. از بخش بسته‌بندی، پلتفرم موردنظر را انتخاب و بسته‌ی خروجی را بساز.

## نکات مهم
- بازی فعلی Three.js و چند افزونه را از CDNهای خارجی بارگیری می‌کند. برای اولین بار اجرا شدن بازی، اینترنت لازم است؛ service worker اسکریپت‌های CDN را پس از دریافت موفق cache می‌کند.
- این بسته برای سازگاری PWA آماده شده، اما هنوز روی PWABuilder یا همه‌ی دستگاه‌ها تست نهایی نشده است.
- برای انتشار عمومی، قبل از ارسال به فروشگاه، تست نصب، حالت آفلاین، چرخش افقی و کنترل‌های لمسی را روی دستگاه واقعی انجام بده.


## اجرای آفلاین
برای آماده شدن کش آفلاین، سایت را یک بار با اینترنت باز کن و صبر کن تا نصب Service Worker کامل شود. سرویس‌ورکر تلاش می‌کند فایل‌های Three.js را هم از CDN ذخیره کند. اگر CDN در زمان نصب در دسترس نباشد، بازی ممکن است تا یک بار بازدید آنلاین بعدی آفلاین نشود. برای آفلاین تضمینی‌تر، کتابخانه‌های Three.js را داخل خود ریپو نگه‌داری و آدرس اسکریپت‌ها را به فایل‌های محلی تغییر بده.


## حالت تمام‌صفحه
مانیفست روی `display: fullscreen` تنظیم شده است. این حالت هنگام اجرای PWA نصب‌شده پشتیبانی می‌شود؛ باز کردن URL عادی داخل Chrome همچنان نوار مرورگر را نشان می‌دهد. برای TWA اندروید، تأیید دامنه با `/.well-known/assetlinks.json` و اثرانگشت گواهی صحیح همچنان لازم است. پس از انتشار، PWA قبلی را حذف/دوباره نصب کنید یا داده/کش آن را تازه کنید تا مانیفست جدید اعمال شود.
